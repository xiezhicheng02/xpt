# bencode 编解码库 说明文档
## 一、概述
这是一款 Go 语言实现的高性能 bencode 编解码库，严格遵循 BitTorrent bencode（BEP-003）规范，支持完整解析、流式增量解析、原始字节零拷贝编码优化，适用于 BitTorrent 种子文件解析、DHT 协议消息处理、P2P 网络通信等场景。

## 二、功能特性
1. **全类型支持**：覆盖 bencode 四种标准数据类型：整数（integer）、字符串（string）、列表（list）、字典（dict）
2. **双解码模式**
    - 完整解码 `Decode`：必须消费全部字节，尾部存在多余字节时报错，适合完整文件解析
    - 流式解码 `DecodeValue`：从指定偏移位置解析，自动推进位置指针，适合嵌套结构、流式数据解析
3. **高性能编码优化**
    - 解析生成的节点自带 `Raw` 原始字节字段，编码时直接复用，性能提升 30 倍以上
    - 基础类型编码全程零堆内存分配，字典编码仅 1 次排序分配
4. **规范严格兼容**
    - 字典编码自动按字节字典序排序，输出结果唯一确定
    - 禁止非法整数格式 `i-0e`
5. **完善的错误体系**：预定义三类错误变量，支持 `errors.Is` 类型断言
6. **丰富的 API**：类型安全的 Getter 方法、独立的单类型编码函数、二进制字节直接编码

## 四、快速开始
### 1. 完整解码
```go
data := []byte("d3:cow3:moo4:spami123ee")
node, err := bencode.Decode(data)
if err != nil {
    // 处理错误
}
// 读取字典值
value, _ := node.GetDictStrValue("cow")
fmt.Println(value) // 输出: moo
```

### 2. 流式增量解码
```go
data := []byte("i42e5:hello")
pos := 0

// 解析第一个整数
intNode, err := bencode.DecodeValue(data, &pos)
// pos 现在指向 4

// 从 pos 继续解析字符串
strNode, err := bencode.DecodeValue(data, &pos)
```

### 3. 编码
```go
// 手动构造节点并编码
node := &bencode.BNode{
    Type: bencode.BDict,
    Dict: map[string]*bencode.BNode{
        "name": {Type: bencode.BString, Str: []byte("test")},
        "port": {Type: bencode.BInt, Int: 8080},
    },
}
encoded := node.Encode()

// 直接使用独立编码函数
intBytes := bencode.EncodeInt(123)
strBytes := bencode.EncodeString("hello")
```

## 五、API 参考
### 5.1 类型定义
| 类型 | 说明 |
|------|------|
| `BType` | 节点类型枚举：`BInt` / `BString` / `BList` / `BDict` |
| `BNode` | bencode 节点结构体 |

`BNode` 字段说明：
- `Type BType`：节点类型
- `Int int64`：整数类型值
- `Str []byte`：字符串类型原始字节
- `List []*BNode`：列表类型元素集合
- `Dict map[string]*BNode`：字典类型键值对
- `DictKeys []string`：字典键原始顺序列表
- `Raw []byte`：节点原始编码字节，用于编码加速

### 5.2 解码函数
| 函数签名 | 说明 |
|--------|------|
| `Decode(data []byte) (*BNode, error)` | 完整解码，必须消费全部字节，尾部多余返回错误 |
| `DecodeValue(data []byte, pos *int) (*BNode, error)` | 从 pos 位置开始解析，解析后 pos 更新为下一个未消费字节位置 |

### 5.3 编码函数
| 函数/方法 | 说明 |
|----------|------|
| `(n *BNode) Encode() []byte` | 节点方法，递归编码整个节点树，优先复用 Raw 字段 |
| `EncodeInt(v int64) []byte` | 独立编码整数 |
| `EncodeString(s string) []byte` | 独立编码字符串 |
| `EncodeBytes(b []byte) []byte` | 独立编码二进制字节数组为 bencode 字符串 |
| `EncodeList(list []*BNode) []byte` | 独立编码列表 |
| `EncodeDict(dict map[string]*BNode) []byte` | 独立编码字典，自动排序键 |

### 5.4 Getter 方法
所有方法均返回 `(值, error)`，节点为 nil 或类型不匹配时返回错误。
| 方法 | 说明 |
|------|------|
| `GetInt() (int64, error)` | 获取整数值 |
| `GetString() (string, error)` | 获取字符串值 |
| `GetHexString() (string, error)` | 获取字符串的十六进制表示 |
| `GetList() ([]*BNode, error)` | 获取列表元素 |
| `GetDictValue(key string) (*BNode, error)` | 获取字典指定键的节点 |
| `GetDictStrValue(key string) (string, error)` | 快捷获取字典字符串值，key 不存在返回 `("", nil)` |
| `GetDictIntValue(key string) (int64, error)` | 快捷获取字典整数值，key 不存在返回 `(0, nil)` |

### 5.5 错误变量
| 错误变量 | 触发场景 |
|----------|----------|
| `ErrUnexpectedEOF` | 数据截断、不完整 |
| `ErrInvalidData` | 格式非法、非法值、尾部多余字节 |
| `ErrUnexpectedTypeData` | Getter 方法类型不匹配 |

## 六、设计要点
### 1. 流式解码指针模式
采用 `pos *int` 指针传递偏移，递归解析时子函数自动推进位置，无需每层返回值传递偏移，代码简洁且性能优秀。

### 2. Raw 字节复用机制
解析阶段每个节点都会保存对应原始字节切片 `Raw`，编码时优先直接输出 Raw，避免重新序列化的 CPU 开销。在「解析 → 少量修改 → 再编码」的典型场景下收益显著。

### 3. 字典有序性保证
- 解析时：`DictKeys` 保留键的原始出现顺序
- 编码时：强制按字节字典序排序输出，严格符合 bencode 规范，保证输出结果唯一

### 4. 错误包装
所有业务错误均通过 `fmt.Errorf("%w: ...", err)` 包装，保留原始错误类型，支持 `errors.Is` 向上层断言错误类型。

## 七、使用注意事项
1. **字节共享风险**：`Str` 和 `Raw` 字段直接引用原始输入数据的底层数组，修改原始输入字节会导致节点值变化；如需长期持有建议手动拷贝。
2. **字典键顺序**：`DictKeys` 仅记录解析时的原始顺序，编码输出会重新排序，不保证与原始顺序一致。
3. **整数约束**：严格禁止 `i-0e` 格式，解析时会返回 `ErrInvalidData`。
4. **nil 节点安全**：所有 Getter 方法均对 nil 节点做了保护，不会 panic。
